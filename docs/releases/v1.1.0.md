# ModSync v1.1.0

Sync exactly what you need, with safer and smaller application updates.

- **Sync All** remains the main action, with separate **Mods**, **Resource Packs**, and **Shaders** actions below it.
- Matching files and settings are left untouched. Unselected categories are skipped, including their order and shader declarations.
- **Publish Resource Pack Order** in Settings adds the enabled shared-pack priority from Minecraft to the push preview. Built-in and personal packs are excluded from the declaration. Upload new shared packs first, arrange them in Minecraft, close Minecraft to save, then enable the setting and push.
- Status counts avoid hashing large packs. Actual syncs verify contents and copied data. Unreadable files abort safely, and settings changed during a sync are preserved.
- Downloads now verify release size, SHA-256, and executable version, support pause/resume and retries, and cache update checks.
- Delta updates reconstruct the exact release EXE from smaller patches when possible, with a verified full-download fallback. The portable layout is preserved.
- The installer keeps the previous EXE as a backup, uses Windows file replacement, and records installation failures for the next launch.

## Updating from v1.0.12 or earlier

Install this release with one full EXE download. Earlier updaters do not understand delta patches. Once v1.1.0 is installed, future releases can use smaller delta downloads. Actual savings vary with code and bundled runtime changes.

Download **ModSync.exe** for ordinary installation. The `.delta` files are for ModSync's updater; do not run them. `SHA256SUMS.txt` is available for manual verification. Existing configuration and Minecraft files continue to be used.
