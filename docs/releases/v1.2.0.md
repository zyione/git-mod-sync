# ModSync v1.2.0

- Back up and verify existing resource packs, shaders, and affected selection settings before downloads overwrite or remove them. Already-current syncs make no backup.
- Clean Reinstall snapshots complete enabled pack folders, including personal files, plus pack settings before rebuilding mods. Backups live in the Minecraft instance's `modsync_backups` folder; the dashboard's Backups action opens it.
- Push resource packs or shaders independently from their dashboard sections. Each confirmation lists only the selected category. Commits exclude unrelated staged changes.
- New modpack repositories use `mods/`; existing root-JAR repositories remain compatible.

Validation: all 58 tests pass, including backups, unavailable backup destinations, personal pack preservation, scoped upload previews, real Git commits with added/updated/deleted files, and light/dark dashboard layouts.
