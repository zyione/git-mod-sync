# ModSync v1.3.0

Mods stay in `zyione/4stoogies-mod-list`. Resource packs now use `zyione/4stoogies-resourcepack-list`; shaders use `zyione/4stoogies-shaderpack-list`.

- Push or sync a pack category without fetching or syncing the mods repository. Only newer changes in the selected repository block its upload.
- Sync All downloads enabled repositories in parallel, then validates and applies one combined plan. If a repository refresh fails, no Minecraft files are changed.
- Configure each repository and branch from the Repositories sheet. Existing config files automatically receive the new defaults; explicitly blank pack URLs retain the single-repository setup.
- Keep pack backups, priority enforcement, active shader selection, and unchanged-file detection.
- Retry failed dedicated-pack uploads without syncing mods. Multi-repository upload failures report categories already uploaded.
- Keep dashboard counts readable and contain progress/actions within the minimum window size.

The two new repositories were seeded with the existing 31 resource-pack files, resource pack order declaration, and 8 shader files. The mods repository remains unchanged.

Validation: 68 automated tests pass, including parallel refresh, independent pushes with newer mods, selected-repository conflict protection, failed-upload retries, backup preservation, and light/dark UI checks. A live download check verified all 39 pack assets by SHA-256, preserved a personal pack, left mods untouched, and confirmed the second sync made no changes.
