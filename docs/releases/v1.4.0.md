# ModSync v1.4.0

Resource Packs and Shaders now each have a separate **Reinstall…** action, plus separate **Sync Order** and **Push Order** actions beside Resource Packs.

- Reinstall only the selected category, with fresh verified copies of all shared packs and a full backup of its folder and selection settings.
- Keep personal packs, other categories, and worlds untouched; remove obsolete managed files.
- Sync only resource-pack order without replacing installed pack files. Missing declarations or required local packs stop safely with a clear message.
- Push only your saved shared-pack priority without uploading pack files or requiring the automatic publishing toggle. Built-in and personal packs are excluded. Unfinished uploads cannot silently enter an order-only push.
- Explicit order sync works independently of automatic order enforcement. Matching order stays untouched; changed settings get a backup.
- Keep counters and primary Sync/Push actions visible, with readable confirmation sheets in light and dark themes.
- Settings' Clean Reinstall now affects only mods.

Validation: 76 automated tests pass, including order-only publishing with locked pack contents, repository refresh without changing selection, pending-upload protection, scoped reinstall backups, matching-file replacement, unrelated locked files, order-only behavior with locked pack contents, no-op order sync, missing-pack protection, refresh/backup failures, and light/dark layouts at the minimum window size.
