# ModSync v1.4.1

Resource Pack Push and Sync now include pack order automatically, with no extra settings required.

- Push pack files and saved Minecraft priority together, including newly uploaded packs in the same commit. Disabled packs upload without becoming enabled.
- Apply shared pack priority during Resource Pack Sync, Sync All, and Resource Pack Reinstall, even with older disabled order preferences.
- Keep separate Push Order and Sync Order for priority-only changes. Push Order excludes local-only personal packs.
- Preserve the existing published order when Minecraft has no saved selection; malformed selections stop the operation before asset writes.
- Keep backups, personal selections, category isolation, and unchanged-file detection. Remove obsolete order switches from Settings.

Validation: 78 automated tests pass, including new-pack upload/order round trip, correct priority with legacy settings disabled, unchanged second sync, separate order publishing, missing-selection preservation, scoped backups, and light/dark layout checks.
