# ModSync v1.5.1

Choose a Minecraft instance on first launch, keep it across updates, and change it from the main screen whenever needed.

- Suggest the current app folder when it contains Minecraft files; detect common launcher instances and official launcher custom game directories. Browse supports custom locations.
- Remember the confirmed folder in config.json. Previously synced installations and existing custom paths retain their selection; missing folders prompt for replacement.
- Follow the selected instance for mods, relative resource/shader paths, Fabric information, and backups. Switching resets verification statuses and ignores stale background results.
- Add Check for Updates to the main screen.
- Keep counters while displaying category verification states. Equal file counts no longer claim that contents match.
- Offer useful failure actions: Retry, Sign In, Choose Instance, Sync Section, Open Backups, and View Logs. Retries return to previews/confirmation; recovery never silently reinstalls or deletes backups.
- Save configuration through a temporary file and preserve the previous selected instance if saving fails.

Validation: 87 automated tests pass, including bounded discovery, invalid-folder rejection, saved-choice reload, upgrade migration, failed-save preservation, recovery routing, matching-count status honesty, and light/dark instance/dashboard layout and contrast checks.

The v1.5.0 release workflow was canceled before publication so the Mods controls could be included in this complete update.
