# ModSync v1.6.0 — A clearer modpack dashboard

The dashboard now leads with your selected Minecraft instance and its synchronization status. Consistent Mods, Resource Packs, and Shaders cards make it easier to see what needs attention and review the next action.

- Clearly labeled local and repository counts; matching counts never imply matching file contents.
- Check Now updates the dashboard in place. Differences show a count and Review changes; healthy sections become quieter.
- Push, reinstall, and resource pack order controls move into category menus. Whole-modpack push and app update checks are under Modpack actions.
- Persistent Instances, Repositories, Backups, and Settings navigation. Account sign-in and whole-modpack clean reinstall are in Settings.
- Desktop sync always previews changes before applying them. Existing upload checks, backups, and destructive confirmations remain in place.
- Compact Fabric status when versions match, with installed versus required details when needed.
- Improved light/dark contrast, keyboard focus, disabled controls, Escape handling, dialog focus containment, and scrolling at smaller window sizes.
- Progress stays visible without scrolling. Temporary success messages clear automatically; errors and backup links remain available.

The comparison engine reports differences to review; it does not infer local/remote direction or conflicts from file counts. Existing remote-change safeguards still apply to push previews.

The supplied design guide is preserved as `ModSyncUI_UI_SKILL.md`, with repository instructions requiring future frontend changes to follow it.

Validation: all 87 tests pass, including rendered dashboard, menu, dialog, busy, changed, synchronized, and smaller-window checks in light and dark themes. The Windows x64 standalone build is verified before publication.
