# ModSync v1.6.1 — Bulk mod exclusions

Exclude several mods at once from Settings → Excluded Mods.

- Drag multiple `.jar` files from File Explorer into the new drop area, or select them together with Choose Files.
- Saves filename exclusions together without moving, copying, or deleting the source files.
- Skips duplicates, mods already covered by exclusion rules, and unsupported items, with a summary of the result.
- Reports save failures and restores the previous exclusions if saving fails.
- Long exclusion names truncate with the full name available in a tooltip.

ModSync now launches with normal permissions so Windows allows drops from File Explorer. Keep ModSync and your Minecraft instance in writable folders. If you explicitly run ModSync as administrator, use Choose Files instead.

Validation: 89 automated tests pass, including bulk exclusion persistence, duplicate handling, save-failure rollback, and light/dark layout checks. Native File Explorer drag gestures still require manual verification.
