# ModSync v1.6.2 — Sync Block app icon

ModSync now has its own cube-and-sync-arrows logo in the Windows taskbar, executable, and app header.

- Bright blue, cyan, and mint on a navy tile for dark mode.
- Deeper cobalt, teal, and jade on a pale tile for light mode.
- The running app's icon follows its selected theme.
- The executable and shortcuts use a fixed icon designed to remain visible on both light and dark backgrounds.
- Nine icon sizes cover small taskbar icons through large Explorer views.

Windows may cache an existing pinned shortcut's icon. If the old icon remains after updating and restarting ModSync, unpin the shortcut and pin the updated app again.

Validation: 89 tests passed for the icon change, light/dark app previews were inspected, and the Windows executable's embedded icon was verified. The release workflow reruns tests and builds the standalone Windows x64 executable and smaller update downloads.
