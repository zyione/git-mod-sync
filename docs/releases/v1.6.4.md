# ModSync v1.6.4 — Easier exclusions and clearer sync results

- Search detected local and repository mods, select multiple checkboxes, and exclude them together. Selections remain checked as you search.
- Use Select Shown and Clear Selection to manage larger selections quickly.
- Enable Keep excluded across updates to exclude Fabric mods by their embedded ID, even when their filenames change. Files without a readable Fabric ID fall back to filename exclusions with a clear explanation.
- Identity exclusions protect personal mods during sync, push, and clean reinstall. Remove them from the active rules list to include those mods again.
- Completion messages now identify updated mods, resource packs, shaders, and applied pack order, and stay visible until dismissed. They explain when to start or restart Minecraft and report Fabric Loader update failures.

Resource-pack sync already applies the repository order when resourcepack-order.txt is provided. The separate Apply repository order action remains available. Close Minecraft before applying pack order so the game does not overwrite the change.

Administrator startup remains enabled. Use Choose Files or the new checkbox selection to exclude multiple mods while elevated; Windows blocks drops from normal File Explorer windows into administrator apps.

Validation: 92 tests pass, including identity exclusions across renamed versions, sync/push/reinstall protection, filename fallback, completion messages, and selection persistence through searches. Light and dark layouts were visually checked.
