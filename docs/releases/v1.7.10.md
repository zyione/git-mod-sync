# ModSync 1.7.10

- **Shared Discord push announcements.** Everyone using this build posts to the same configured channel when pushing through ModSync. No webhook setup is needed on individual PCs.
- One push produces one combined message, grouping successfully uploaded changes into Mods, Resource packs, and Shader packs. File names include added, updated, and removed labels; folder packs appear once.
- Published mod updates remind players to sync before playing. Resource packs and shaders use optional sync wording. If publication is still needed, the message explains that before players try syncing.
- Partial uploads announce only repositories that succeeded. Failed and no-op pushes, ordinary checks, and player downloads do not announce. Notification failures leave successful uploads intact and show a warning.
- The destination is supplied through a private, gitignored build `.env` or encrypted GitHub Actions secret and embedded into the executable. The webhook URL stays out of source files and logs; the shared destination is visible as enabled in Settings.
- Includes the 128×128 JPG ModSync logo for the Discord webhook avatar.
- Retains the player storage and repeated cleanup improvements from versions 1.7.8 and 1.7.9.
