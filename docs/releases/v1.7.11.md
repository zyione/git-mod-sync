# ModSync 1.7.11

- **Optional faster syncs and pushes.** Enable **Settings → Keep repository copies** to reuse local copies when you have extra disk space. The option is off by default for new and existing installations.
- Keeps authoring repositories for later pushes and publication, and verified downloads for later syncs and reinstalls. Cached downloads are checked against published checksums before reuse; damaged copies are downloaded again.
- Turning the option off restores safe cleanup after use, successful verification, or the next dashboard startup. Unpublished repository changes remain protected.
- Includes a saved preference, accessible settings control, and light/dark layout checks at the app's compact window size.
- Retains shared Discord push announcements and the existing default storage-saving behavior.
