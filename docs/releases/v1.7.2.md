# ModSync 1.7.2

## Move ModSync outside a BigChadGuys instance

Opening ModSync from inside a BigChadGuys instance now asks you to confirm the detected UltimMC folder or choose another one.

- Creates `UltimMC\ModSync` after confirmation if the folder is missing.
- Verifies the copied executable and waits for the new copy to confirm startup before removing the original executable.
- Offers to open an existing destination copy without overwriting it or deleting the old copy.
- Cancel leaves everything in place. Failed relocation preserves the original executable.
- Leaves game files, existing launch commands, and other old files in place. Matching legacy settings can be imported during instance selection.

After moving, confirm your instance and personal-mod exclusions, update old shortcuts, and review **Launch check** setup with UltimMC closed. If launched through an old pre-launch command, ModSync cancels that launch and asks you to open the app directly first.

Validation: 140 automated tests pass, including missing-folder creation, conflicting destination protection, corrupted-copy handling, changed-original preservation, and light/dark layout checks. Development and testing did not modify real player instances.
