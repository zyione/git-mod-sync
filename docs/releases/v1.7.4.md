# ModSync v1.7.4

- Check Now and UltimMC launch checks focus on mods and the configured Fabric Loader version. Resource packs, shaders, and resource-pack order are optional and no longer block a healthy mod check.
- Optional content can still be checked and synced separately. Sync All and Full verification continue to cover all enabled categories.
- Fixed repeated options.txt sync prompts when Minecraft uses equivalent JSON spacing or character escaping for resource-pack selections.
- Successful syncs now refresh the dashboard with the verified result instead of keeping the previous changes-to-review status.
- Verification and recovery follow the selected categories, preserving ownership and recovery information for optional content.

Validated with 145 automated checks, including both dashboard themes and disposable Minecraft instances.
