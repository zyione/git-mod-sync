# ModSync v1.7.5

ModSync updates now take priority over modpack content.

- Wait for the app update check before checking mods, resource packs, shaders, or Fabric.
- When a newer ModSync release is available, update and restart ModSync before checking or changing content, pushing changes, publishing a pack, or continuing a launcher check.
- Closing the update prompt keeps content operations paused. Failed or paused downloads can be retried without bypassing the app update.
- Startup app checks contact GitHub immediately. Content actions reuse cached app metadata, and can continue offline when no app update is known.
