# ModSync v1.7.6

- Remove the personal-mod exclusion reminder from startup and launch checks. Existing exclusions still apply and remain editable in Settings.
- Mods Push now publishes a modpack version after uploading, so player checks can detect the updates without a separate publishing step.
- Preserve previously published resource packs and shaders when publishing a Mods push. Push modpack publishes all enabled categories.
- Publish already uploaded mods by choosing Mods Push again, even when there are no new local file changes.
- Report upload and publication failures separately so an uploaded file is not mistaken for an update available to players.
