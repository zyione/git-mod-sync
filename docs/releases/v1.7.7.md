# ModSync 1.7.7

- **Reinstall only** is the recommended reinstall action. It deletes non-excluded mods and installs fresh repository copies without making a backup. Choose **Back up and reinstall** when testing and you need recovery files. Each category and the entire modpack offer both choices.
- On the first dashboard launch of this version, ModSync removes existing backups inside its portable app folder, old `ModSync.before-*.exe` copies, and completed update downloads. This permanently removes those old backups. New optional reinstall backups survive later launches.
- Automatic sync/loader backups retain the newest recovery snapshot and up to three snapshots within a 512 MiB budget. A single newest snapshot may exceed that budget. Explicit reinstall backups are excluded from routine retention.
- Old logs expire after 14 days. Recent partial update downloads remain resumable. The previous executable is removed after an installed update reports success to the dashboard.
- The release is still one self-contained Windows executable. Repository caches are retained for sync and publishing and can remain large; this release does not eliminate that storage requirement.
- Cleanup only targets known files inside the portable app folder. Instance content, worlds, personal exclusions, settings, launch hooks, repositories, and legacy external recovery folders are preserved. Linked cleanup paths are skipped and retried.
