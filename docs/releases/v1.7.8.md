# ModSync 1.7.8

- **One installed copy for players.** ModSync compares installed mods, resource packs, and shaders against the published file list and checksums. Player sync and reinstall no longer need a second modpack or a Git checkout.
- Existing clean repository caches inside the portable app folder are removed when the dashboard starts. Cleanup is local-only; it does not fetch the repository or provision Git. Caches with unpublished edits, untracked files, or unpushed commits are preserved for recovery, as are custom caches outside the portable app folder and linked paths.
- Verified downloads are consumed after installation. Successful verification clears leftover content downloads, and startup clears stale content staging files. Incomplete operations can retain temporary downloads until retry or the next launch.
- Only changed files download during normal syncing. Up to four downloads run concurrently; files with identical content share one download. Valid local fingerprints keep routine checks fast without storing copies of assets.
- Reinstall uses the published version and refreshes selected shared files. **Reinstall only** makes no asset backups; **Back up and reinstall** explicitly saves a recovery snapshot. Worlds, excluded mods, and local-only personal packs remain protected.
- Ordinary player updates no longer create automatic copies of replaced mods or packs. Temporary Git repositories are still used for authoring/publishing and are removed after those operations or cancellation when verified safe. Unfinished uploads are retained.
- Temporary space is needed while downloading and replacing files, plus small configuration, checksum, and recovery metadata. Explicit backups remain an intentional extra copy. This does not modify your selected Minecraft instance during the application update itself.
